# Coding Practice & Study Notes

This repository contains my solutions and practice for **Data Structures & Algorithms (DSA)** using problems from **NeetCode**.

The main goal is to build strong problem-solving skills, understand common algorithmic patterns, and prepare for technical interviews.

## What I Practice

* Arrays & Hash Tables
* Two Pointers
* Sliding Window
* Stack & Queue
* Binary Search
* Linked Lists
* Trees
* Graphs
* BFS & DFS
* Heap / Priority Queue
* Backtracking
* Greedy Algorithms
* Dynamic Programming
* Tries
* Sorting

## Study Approach

For each problem, I focus on more than just getting an accepted solution. I try to understand:

1. **Which algorithmic pattern applies to the problem.**
2. **Why a specific data structure is useful.**
3. **How to derive the solution step by step.**
4. **Time and space complexity.**
5. **How to improve an initial solution.**
6. **Which concepts can be reused in other problems.**

Some problems contain multiple submissions. This allows me to track my progress and compare different approaches as I improve my understanding.

## Goal

The main goal is to become better at recognizing **patterns, choosing the right data structures, analyzing complexity, and writing clean and efficient code**.

This repository serves as a record of my continuous practice with algorithms and data structures, with a focus on improving my problem-solving skills for technical interviews and real-world software development.
